1. 这是什么

这是 Lucubratio 的公开版：一套把「任意课程内容」编译成可离线学习的内容包的流水线，外加一个只读的查看器（WebView 壳）。

它本身不含任何课程内容——你看到的两页只是演示格式的样例。真正的课程，由你用这套流水线自己生成。

一句话：流水线负责"把知识变成能读、能自测、能复习的页面"，查看器负责"离线读它、记进度、排复习"。

2. 三个组成部分

部分位置干什么
内容规范docs/CONTENT-SPEC.md一页内容该怎么写（标题、公式、图、自评单元、图片）
生成流水线scripts/build.mjs把源 HTML 编译成可运行站点（注入壳、公式转 MathML、打自评标记、建检索索引）
查看器web/ + android/离线阅读、进度、FSRS 复习、搜索、统计

3. 两分钟跑起来

  1. 装依赖：无需 npm install——纯 Node 20+，零第三方依赖（Mermaid / KaTeX 已内置在 web/vendor）。
  2. 编译内容：node scripts/build.mjs，产物在 android/app/src/main/assets/web/。
  3. 校验产物：node scripts/verify.mjs（图片是否存在、锚点是否有效、公式/图数量基线）。
  4. 出 APK：npm run build:debug（需要 Android SDK 与 JDK 17）。

4. 本仓库的边界（重要）

  • ✅ 提供：格式规范、编译器、查看器、校验器、示例页。
  • ⛔ 不提供：任何课件、讲义截图、教材内容。这些属于各自的权利人。
  • ⚠️ 你用本流水线生成的课程，版权与合规由你自己负责——尤其是把课堂 PPT/PDF 转成内容时，通常只适合个人学习使用。

5. 下一步

想接自己的课程，看这两份文档：

  • docs/CONTENT-SPEC.md：一页内容长什么样，自评单元怎么标。
  • docs/PACKAGE-FORMAT.md（规划中）：课程包 .lcr 的结构，以及未来"导入 App"的约定。

6. 随堂检测

检测 1（10 分）本仓库的「流水线」主要负责什么？（　　）

A. 提供课程内容 B. 把源 HTML 编译成可运行站点（注入壳、公式、自评标记、检索索引） C. 提供在线课程市场 D. 存储用户的复习记录

解析：B 对。scripts/build.mjs 负责注入壳层资源、把公式转成 MathML、给命中规则的标题打 data-qid、生成检索索引与 manifest。A 错，仓库刻意不含课程内容；C 错，这里不做分发平台；D 错，复习记录由查看器的 IndexedDB + FSRS 负责，与流水线无关。（依据：scripts/build.mjs 与 README「快速开始」）
