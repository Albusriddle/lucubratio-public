# 踩坑清单（按报错查）

## 构建 / 校验

| 现象 | 原因 | 处理 |
|---|---|---|
| `✗ os-XX: 图表源码里出现非法的 <script / </script>` | Mermaid 块写成了多行，`<div class="mermaid">` 后换行再写 `<script>` | 必须写成 `<div class="mermaid"><script type="text/plain">flowchart TD`（同一行开头） |
| `✗ 正文残留 Markdown 星号：os-XX` | 正文里写了 `**加粗**` | 改 `<strong>…</strong>`；`#` 标题同理改成 `<h2>` |
| `✗ 锚点失效 / 目录缺项` | `h2/h3` 少了 `id`，或 id 重复 | 补唯一 id；重复的改掉（如两个「本段导读」） |
| `✗ 内联 mermaid 块少得可疑` | 图被写成了字符画或图片 | 改回 Mermaid；字符画在手机上必然错位 |
| `✗ 公式少得可疑` | 公式被写成了纯文本 | 用 `<code>` 包 LaTeX 或 MathML |
| `✗ 自评单元数与各页合计不一致` | `QUESTION_RULES` 里没有该页规则，或标题不是「检测 N」 | 加规则：`'os-XX': { level: 3, test: /^检测\s*\d+/ }` |
| `✗ 页面引用了不存在的图片` | 图片写 `.png` 但资产是 `.webp` | 一律用 `.webp` |
| `✗ 产物超预算（>24MB）` | 图片没压 | WebP quality≈82；必要时降 DPI 到 130 |

## 打包 / 导入

| 现象 | 原因 | 处理 |
|---|---|---|
| `E_HTML: 内联 <script>` | 页面里有内联脚本 | 只允许 `<script type="text/plain">`（Mermaid）与 `/shell/*.js` |
| `E_HTML: 外部/可执行 URL` | 图片/链接写成了 `http(s)://` | 改站内相对路径 |
| `E_PATH: 包内存在不安全路径` | 有人手工改了 zip | 用 `scripts/pack.mjs` 重新打包，别手改 |
| `E_APP_TOO_OLD` | 包的 `appMin` 高于 App 版本 | 降低 `--appMin` 或升级 App |
| 导入成功但首页没变化 | 页面没下拉刷新 | 导入后会自动刷新；若卡住，杀进程重开 |
| 导入后点课程页 404 | `pack` 后手工删过文件 | 重新 `build` → `pack`，一次性做完 |

## 生成阶段（不是脚本报错，但会毁掉质量）

| 现象 | 处理 |
|---|---|
| 无文字层页面（`report.json.empty_pages`）被"合理推测"填满 | 必须看 `img/pNNN.webp`；看不懂就写「据图：…」或标注「课件未展开」 |
| 两份稿子高度雷同 | A/B 必须独立，不能给同一份笔记；若已相同，重跑其中一份 |
| reviewer 只说"两者差不多" | 视为没复核；要求逐条给页码与采信结论 |
| 检测题解析没有页码 | 回课件找页码；找不到说明该结论是编的，删题 |
| 一页写得过长（>8000 字） | 拆成两页，`id` 保持不变前缀 |
