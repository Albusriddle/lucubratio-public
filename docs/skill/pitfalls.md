# 踩坑清单（按报错查）

## 构建 / 校验

| 现象 | 原因 | 处理 |
|---|---|---|
| `✗ os-XX: 图表源码里出现非法的 <script / </script>` | Mermaid 块写成了多行，`<div class="mermaid">` 后换行再写 `<script>` | 必须写成 `<div class="mermaid"><script type="text/plain">flowchart TD`（同一行开头） |
| `✗ 正文残留 Markdown 星号：os-XX` | 正文里写了 `**加粗**` | 改 `<strong>…</strong>`；`#` 标题同理改成 `<h2>` |
| `✗ 锚点失效 / 目录缺项` | `h2/h3` 少了 `id`，或 id 重复 | 补唯一 id；重复的改掉（如两个「本段导读」） |
| `✗ 内联 mermaid 块少得可疑` | 图被写成了字符画或图片 | 改回 Mermaid；字符画在手机上必然错位 |
| `✗ 公式少得可疑` | 公式被写成了纯文本 | 用 `<code>` 包 LaTeX 或 MathML |
| `✗ 自评单元数与各页合计不一致` | `QUESTION_RULES` 里没有该页规则，或标题不是「检测 N」 | 加规则：`'os-XX': { level: 3, test: /^检测\s*\d+/ }` |
| `✗ 页面引用了不存在的图片` | 图片写 `.png` 但资产是 `.webp` | 一律用 `.webp` |
| `✗ 产物超预算（>24MB）` | 图片没压 | WebP quality≈82；必要时降 DPI 到 130 |
| `✗ 缺少解析块：解析必须写成 <blockquote><strong>解析</strong>…` | 检测题的解析写成了 `<p><strong>题解</strong>>`+`<ul>`，或整段没写解析 | 改成单个 `<blockquote><strong>解析</strong>：X 对。…（页码）</blockquote>`，紧跟第 4 个选项。历史内容可临时加 `--allow-nonblockquote`，新内容不要用 |
| `DOM id 可疑（静态分析）：xxx.html: home.js 使用 #yyy` | 页面缺该 id，或脚本里靠 `setText('id')` 写入而页面没这个元素 | 先跑 `npm run check:pages`（真机逐页抓异常）确认；真缺就给页面补元素，能跑通则忽略（静态分析看不见"调用点守卫"） |

## 打包 / 导入

| 现象 | 原因 | 处理 |
|---|---|---|
| `E_HTML: 内联 <script>` | 页面里有内联脚本 | 只允许 `<script type="text/plain">`（Mermaid）与 `/shell/*.js` |
| `E_HTML: 外部/可执行 URL` | 图片/链接写成了 `http(s)://` | 改站内相对路径 |
| `E_PATH: 包内存在不安全路径` | 有人手工改了 zip | 用 `scripts/pack.mjs` 重新打包，别手改 |
| `E_APP_TOO_OLD` | 包的 `appMin` 高于 App 版本 | 降低 `--appMin` 或升级 App |
| 导入成功但首页没变化 | 页面没下拉刷新 | 导入后会自动刷新；若卡住，杀进程重开 |
| 导入后点课程页 404 | `pack` 后手工删过文件 | 重新 `build` → `pack`，一次性做完 |
| `✗ 包内有 N 张未被页面引用的图片` | 页面里没有 `/img/…` 引用，却把图片塞进了包 | `pack` 现在只打"被页面引用"的图：删掉多余图片，或在正文里用 `<figure class="sa-ppt" data-ppt="…">` 正确引用后在 `build` 阶段回填 |

## 生成阶段（不是脚本报错，但会毁掉质量）

| 现象 | 处理 |
|---|---|
| 无文字层页面（`report.json.empty_pages`）被"合理推测"填满 | 必须看 `img/pNNN.webp`；看不懂就写「据图：…」或标注「课件未展开」 |
| 两份稿子高度雷同 | A/B 必须独立，不能给同一份笔记；若已相同，重跑其中一份 |
| reviewer 只说"两者差不多" | 视为没复核；要求逐条给页码与采信结论 |
| 检测题解析没有页码 | 回课件找页码；找不到说明该结论是编的，删题 |
| 一页写得过长（>8000 字） | 拆成两页，`id` 保持不变前缀 |

## 解析被学生提前看到 / 点了没反应

| 症状 | 原因 | 改法 |
|---|---|---|
| 一打开页面就看到答案 | 解析没写成独立的 `<blockquote>` | 解析必须紧跟第 4 个选项、单独成块；查看器只折叠以「解析」开头的 blockquote |
| 没有「查看解析」按钮 | 解析开头不是「解析」（如写成「答案：」） | 首句统一写 `<strong>解析</strong>：X 对。…` |
| 自己加的折叠按钮样式怪 | 壳层已自动加，重复了 | 删掉自写的 `<details>` / 按钮 |

## 把课程包传上去了（红线）

`.lcr`、课程正文页、课程图片**一律不进 git / 不进 Releases**。详见仓库根目录 `AGENTS.md`。
`node scripts/verify.mjs` 会检查并直接失败。

## 课件截图相关

| 症状 | 原因 | 改法 |
|---|---|---|
| 构建报「缺课件截图: xxx → /img/vm1/p042.webp」 | 图没渲染过 | 先跑 `node tools/ppt-shots.mjs --all --src <课件目录>`（或不给 `--src` 而设环境变量 `COURSE_PDF_DIR`） |
| 构建报「data-ppt 写法无法解析」 | 写成 `data-ppt="p42"` / `05-42` | 只能 `42` 或 `05:42` |
| 正文里出现原始标记文字 | 直接写在文本里、没落在 `<p>` 之间 | 标记要独占一行、放在段落之后 |
| 图出现在不相干的位置 | 段落里恰好先提到了那个页码 | 人工/复核时把 `<figure>` 挪到正确段落之后 |
| 期中页图太多 | 跨讲引用逐条命中 | 正常现象（用户已确认不设单页上限） |
