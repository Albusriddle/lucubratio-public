# 页面模板：四块结构

每一页（对应一个课件或一个主题）都按这四块写。**不要**写成流水账。

```html
<h2 id="1-这一节讲什么">1. 这一节讲什么</h2>
<p>3–5 句：解决什么问题、关键概念、学完能答哪类题。</p>

<h2 id="2-正文展开">2. 正文展开</h2>
<h3 id="2-1-核心概念">2.1 核心概念</h3>
<p>定义 + 一句话直觉 + 一个最小例子。</p>

<h3 id="2-2-机制与流程">2.2 机制与流程</h3>
<div class="mermaid"><script type="text/plain">flowchart TD
  A["起点"] --> B["中间"]
  B --> C["结果"]
</script></div>

<h2 id="3-易错点">3. 易错点</h2>
<blockquote><strong>常见误解</strong>：最容易搞反/混淆的那一点（课件 p42）。</blockquote>

<h3 id="检测 1">检测 1（10 分）题干</h3>
<p>A. …　B. …　C. …　D. …</p>
<blockquote><strong>解析</strong>：逐项错因 + 页码。</blockquote>
```

## 硬性约定

| 项 | 要求 |
|---|---|
| `h2` | 至少 3 个（讲什么 / 展开 / 易错点）；`id` 形如 `1-这一节讲什么`（数字-短标题，不含空格以外的符号也行） |
| `h3` | 小节 + 检测题；检测题 `id` 必须是 `检测 N`（`QUESTION_RULES` 靠这个匹配） |
| Mermaid | `<div class="mermaid"><script type="text/plain">flowchart TD` **同一行开头**，`</script></div>` 结尾；节点文字用双引号 |
| 表格 | 用 `<table>`；窄屏会自动横向滚动（壳层 `.table-wrap`） |
| 代码 | `<code>` 或 `<pre>`，禁止用 `**` `#` 之类 Markdown 记号 |
| 引用 | `<blockquote>` 用于「要点提示」和「解析」 |
| 图片 | 用 Mermaid 或 `img/NN.webp`；**不要**贴课件截图以外的东西（版权） |

## 课件截图标记

```html
<p>这一节的三条结论都来自同一张图：进程地址空间的六个段（课件 p11）。</p>
<figure class="sa-ppt" data-ppt="11"></figure>
```

| 场景 | 写法 |
|---|---|
| 同讲页面 | `data-ppt="11"` |
| 期中/复习页跨讲引用 | `data-ppt="05:11"`（讲次:页码） |

构建期替换为 `<img src="/img/<deck>/pNNN.webp" loading="lazy">` + `<figcaption>课件 pNN</figcaption>`，
点击可全屏放大。**不要直接写 `<img>`**。

## id 命名建议

```
1-这一节讲什么
2-正文展开
2-1-核心概念
2-2-机制与流程
3-易错点
检测 1
检测 2
```

要点：**稳定可预测**。因为卡片按 `cid + # + id` 记账，`id` 一改，旧卡片就会变成"待复核"。

## 一页多长合适

| 课件页数 | 建议正文长度 | 检测题 |
|---|---|---|
| 10–20 页 | 1500–2500 字 | 3–5 道 |
| 30–50 页 | 3000–5000 字 | 5–8 道 |
| 60+ 页 | 拆成两页写 | 每页 5–6 道 |

宁可拆成两页，也不要把一页写到 8000 字——手机上读不动，复习也切不开。
