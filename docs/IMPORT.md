# 怎么做一个自己的课程包

> 目标：把「你的课程内容」变成 App 里能读、能自测、能复习的课程包（`.lcr`）。
> 全程离线，不需要服务器，也不需要账号。

---

## 0. 你需要什么

| 需要 | 说明 |
|---|---|
| Node 20+ | 跑本仓库的构建脚本（零第三方依赖，不用 `npm install`） |
| 内容源 | 你自己写的 HTML（格式见 [`CONTENT-SPEC.md`](CONTENT-SPEC.md)） |
| 一台能装 App 的手机 | 用来读、测、复习 |

---

## 1. 写内容

在 `content/os/` 下按 `NN_标题.html` 命名放页面，每页照 [`CONTENT-SPEC.md`](CONTENT-SPEC.md) 的骨架写：

```html
<h2 id="1-本节讲什么">1. 本节讲什么</h2>
<p>…</p>
<h3 id="检测 1">检测 1（10 分）题干…</h3>
<p>A. … B. … C. … D. …</p>
```

- 每个 `<h2>/<h3>` 都要有**页内唯一**的 `id`（目录、搜索、锚点都靠它）
- 想让它成为「可自评单元」，标题要能被 `scripts/build.mjs` 的 `QUESTION_RULES` 命中
- 图用 Mermaid；**不要贴字符画**（手机上必然错位）

## 2. 配自评规则

打开 `scripts/build.mjs`，在 `QUESTION_RULES` 里给这一页加一条：

```js
'os-03': { level: 3, test: /^检测\s*\d+/ },   // os-03 就是 content/os/03_xxx.html
```

> 配了规则却一个都没命中，构建会直接报错——这是故意的，防止你写错前缀还以为生效了。

## 3. 编译并校验

```bash
node scripts/build.mjs      # 注入壳层 / 公式转 MathML / 打自评标记 / 生成索引
node scripts/verify.mjs     # 锚点、图片、公式基线、自评单元数
```

## 4. 打成课程包

```bash
node scripts/pack.mjs --id my-course --title "我的课程" --version 1.0.0
```

产物：`dist/my-course-1.0.0.lcr`（约几百 KB 到几十 MB，取决于图片）。

约束：

| 字段 | 规则 |
|---|---|
| `--id` | 小写字母/数字/连字符，≤64 字符，**全局唯一**（重复会覆盖旧课程） |
| `--version` | `x.y.z`；同 id 换了版本再导入 = **更新**（旧卡片会进"待复核"） |
| `--title` | 首页显示的名字 |

## 5. 校验课程包（分发前必做）

```bash
node scripts/verify-package.mjs dist/my-course-1.0.0.lcr
```

它会检查：zip 安全（无 `..`/绝对路径）、结构完整、页面与清单一致、**页面里的 HTML 是否安全**（禁内联脚本/on* 属性/外链、禁 iframe 等）、体积与 `format.bytes`。

## 6. 在 App 里导入

1. 把 `.lcr` 传到手机（微信/数据线/网盘都行）
2. 打开 App → 首页「＋ 导入课程包」→ 选文件
3. 成功会弹「已导入《你的课程》N 页」，首页出现「我的课程」段
4. 之后就能：阅读、自评、进复习队列、被全文搜索到

> 删除：课程右侧「删除」点两次（3 秒内），会同时清掉这门课的进度/卡片/日志。

## 7. 出错时看这里

| 错误码 | 含义 | 怎么办 |
|---|---|---|
| `E_PATH` | 包内有 `..` 或绝对路径 | 检查打包工具，别手工改 zip |
| `E_EXT` | 有不在白名单的文件类型 | 只允许 html/json/图片/字体/纯文本 |
| `E_TOO_BIG` / `E_TOO_MANY` | 超过 200MB 或 5000 个条目 | 拆成两门课，或压缩图片 |
| `E_FORMAT` / `E_FORMAT_VERSION` | 不是 `lcr/1` 或字段缺失 | 用本仓库的 `pack.mjs` 重新打包 |
| `E_APP_TOO_OLD` | 包要求的 App 版本更高 | 升级 App，或把 `--appMin` 调低后重打 |
| `E_ID` | id 不合法 | 只用小写字母/数字/连字符 |
| `E_ZIP` | 不是有效的 zip（或文件被截断） | 重新打包；或清理手机空间后重试 |
| `E_CRC` | 解压后大小与 zip 记录不符，通常意味着文件损坏 | 重新打包；或清理手机空间后重试 |
| `E_IO` | 读写失败（空间不足、权限问题、临时目录建不出来） | 重新打包；或清理手机空间后重试 |
| `E_MANIFEST` | 清单里的页面在包里找不到 | 重新 `build` 后再 `pack`（别手工删文件） |
| `E_SEARCH` | search.json 损坏 | 同上，重新构建 |
| `E_HTML` | 页面含不安全内容 | 看提示里指出的规则（内联脚本/on*/外链/iframe…） |
| `E_COMMIT` | 写盘失败 | 检查手机剩余空间 |
